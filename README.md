# Las Peñas, Guayaquil

Sitio web de una sola página que presenta el barrio de Las Peñas: su historia, las actividades que se pueden hacer y las opiniones de residentes y turistas.

Proyecto desarrollado para la materia de Desarrollo de Aplicaciones Web y Móviles en la ESPOL.

## Autores

- **Nombres:** Andy Cobeña y Martin Suazo
- **Carrera:** Ingeniería en Ciencia de Datos e Inteligencia Artificial
- **Universidad:** Escuela Superior Politécnica del Litoral (ESPOL)
- **Paralelo:** 3
- **Período:** II PAO 2026

## Descripción

La página está organizada en secciones de pantalla completa con desplazamiento suave:

1. **Encabezado:** título del proyecto y botón de inicio.
2. **Historia:** origen y relevancia de Las Peñas.
3. **Actividades para hacer:** subir el Cerro Santa Ana, recorrido artístico y galerías, ruta histórica y arquitectónica, gastronomía y vida nocturna.
4. **Comentarios de residentes y turistas:** testimonios sobre la experiencia en el barrio.

## Tecnologías

- HTML5
- CSS3
- JavaScript (incluido en la plantilla: jQuery, Scrollex, Scrolly, Breakpoints)
- [Font Awesome Free 5.15.4](https://fontawesome.com) para los íconos
- Tipografía Raleway (Google Fonts)

## Cómo ejecutarlo

1. Descarga o clona el repositorio.
2. Abre la carpeta del proyecto.
3. Haz doble clic en `index.html` para abrirlo en el navegador.

No requiere instalación ni servidor. Para verlo con recarga automática puedes usar la extensión **Live Server** de VS Code.
